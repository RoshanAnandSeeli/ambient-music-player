# Ambient Music Player

A minimal, beat-reactive music player that runs entirely in the browser — no installs, no backend.

## How to use

1. Open `index.html` in any modern browser
2. Click **+ Add Tracks** to load one or more audio files from your device
3. Hit play — the background, particles, and artwork all react to the beat

## Controls

- **⏮ / ⏭** — previous / next track
- **⇄** — shuffle queue
- **↺** — cycle loop modes (off → loop all → loop one)
- **♩** — open lyrics panel (paste lyrics, click Edit to save them per track)
- **☰** — open queue panel (click any track to jump to it)
- **☀** — toggle light / dark mode
- Click the **album artwork** to fullscreen it
